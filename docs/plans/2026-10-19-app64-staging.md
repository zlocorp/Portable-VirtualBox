## Design decisions

- Windows Installer databases are opened with MSIDBOPEN_READONLY. Only fixed SELECT queries and read-only stream access are used.
- Only descendants of the verified application root are staged. System/shortcut directories are not mapped into Windows.
- File table identifiers map cabinet members to target long filenames. Media LastSequence ranges determine cabinet membership.
- Cabinet.dll FDI receives only an opaque source token. Application-owned callbacks perform Unicode-aware reads and exclusive writes in private staging; spanning cabinets fail closed.
- Existing app64/user VM trees are never updated in place. Publish a new tree only after all preparation validators succeed.
- Supported input is the pinned Oracle family, not arbitrary MSI installation compatibility. Unknown schema or unsupported layout fails closed.
- No install conditions/custom actions are evaluated; no COM registration, service creation or Windows 11/VM acceptance is implied.
- A trusted user-selected parent directory is required. No claim of resisting privileged concurrent directory-topology mutation.
